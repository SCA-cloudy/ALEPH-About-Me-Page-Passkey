## 3. 시험 중 있었던 문제

- 15:06 첫 등록 요청이 500: 서버 키에 표 사용 권한이 없었음(`db GET passkey_accounts -> 403`). SQL로 서버 키에만 권한을 줘서 해결(`db/schema.sql`, 커밋 02b913b).
- 두 번째 패스키를 같은 Google 비밀번호 관리자에 만들 수 없었음: 사용자 식별값이 같으면 새 패스키가 옛 것을 덮어쓰기 때문. 패스키마다 식별값을 다르게 바꿈(커밋 65cee61). 이 PC에는 Windows Hello가 없었고 PC 설정을 바꾸지 않기로 해서 이 방법을 택함.
- 외부 라이브러리(SimpleWebAuthn 등)를 쓰려 했으나 작업 환경에서 npm 레지스트리에 접속할 수 없어, Node 내장 `crypto`로 직접 구현함.
